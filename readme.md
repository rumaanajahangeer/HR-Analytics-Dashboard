# HR Analytics Dashboard (Python + SQL + Excel + Power BI)

## Business Problem

An organization wants to analyze its employee workforce, salary patterns, demographics, departments, job roles, and employee attrition to better understand workforce trends and support HR decision-making.

## Objectives

* Analyze employee workforce distribution.

* Measure employee attrition and attrition rate.

* Identify departments with higher attrition.

* Analyze employee demographics such as gender and education.

* Analyze salary patterns across departments and job roles.

* Understand employee tenure and years at the company.

* Build an interactive HR Analytics Dashboard for management.

## Project Objective

Build an end-to-end HR analytics solution using Python, SQL, Excel, and Power BI by preparing employee data, performing workforce and attrition analysis, and developing an interactive dashboard for HR decision-making.

## Project Workflow

### 1. Data Generation & Preparation (Python)

* Generated a realistic HR employee dataset containing 5,000 employee records.

* Used Python and Pandas to create employee information and HR-related attributes.

* Included employee demographics, departments, job roles, education, salary, years at company, and attrition information.

* Exported the prepared dataset for further analysis.

### 2. Data Analysis (SQL)

* Imported the HR dataset into MySQL.

* Performed employee and workforce analysis.

* Calculated employee counts and attrition metrics.

* Analyzed attrition across departments and employee categories.

* Analyzed salary and employee tenure.

* Used SQL queries to generate business-focused HR insights.

### 3. Data Preparation & Analysis (Excel / Google Sheets)

* Imported HR employee data from CSV files.

* Performed data cleaning and initial exploration.

* Created pivot tables for department, gender, education, and attrition analysis.

* Analyzed salary and years-at-company patterns.

* Created charts and summaries for HR insights.

* Prepared data for Power BI visualization.

### 4. Data Visualization (Power BI)

Built an interactive HR Analytics Dashboard containing:

* Total Employees

* Attrition Rate

* Average Salary

* Department-wise Attrition

* Gender Distribution

* Education Analysis

* Job Role Analysis

* Years at Company Analysis

* Employee Attrition Analysis

* Interactive filters and slicers

* Employee Details Drill-through Page
